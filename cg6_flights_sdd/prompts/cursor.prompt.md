# Prompt para Cursor — CG6 Flights

Trabaja únicamente bajo las specs aprobadas.

- spec aplicada;
- archivos tocados;
- módulo afectado;
- permisos involucrados;
- auditoría requerida;
- pruebas necesarias;
- riesgos.

No modifiques arquitectura sin ADR.
