# Prompt de revisión para agentes IA — CG6 Flights

Revisa el cambio contra:

- Product Spec.
- Architecture Spec.
- Frontend Spec.
- Backend Spec.
- Database Spec.
- Security Spec.
- API Contracts.
- Testing Spec.
- AI Rules.
- Quality Gates.

Marca como FAIL si detectas:

- secretos;
- acceso indebido;
- ruptura de módulos;
- falta de auditoría;
- falta de permiso;
- falta de tests;
- dependencia injustificada;
- API no documentada.
